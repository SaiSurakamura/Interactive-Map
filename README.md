# 🏫 3D-Карта Колледжа

Интерактивная схема кампуса с цветовой индикацией занятости аудиторий
по расписанию в реальном времени.

## Статусы
- 🟢 Свободно — можно зайти
- 🔴 Идёт пара — не беспокоить
- 🟠 Скоро начнётся (≤15 мин)
- ⚪ Недоступно / служебное

## Возможности макета
- Переключение этажей (1–3)
- Вкл/выкл внешних стен, перегородок, подписей, цветов расписания
- Ракурсы: сверху / изометрия / свободное вращение мышью
- Поиск аудитории по номеру или названию (с авто-переходом на нужный этаж)
- Инфо-панель с расписанием и ближайшим статусом
- Часы реального времени + авто-обновление статусов каждые 30 сек
- Адаптив (мобильное выезжающее меню, нижняя шторка инфо-панели)

## Запуск
Через **Live Server** (не `file://`). Открыть `index.html`.

## Стек
HTML5 · CSS3 (glassmorphism, 3D transforms) · Vanilla JS · без сборки и бэкенда.
